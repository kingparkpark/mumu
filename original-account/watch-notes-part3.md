# 亲自观看笔记 Part 3

## V07 红发 vs 白发废墟对决（84秒，无台词，Flova.ai）
- 色彩即阵营：白发=紫电/紫瞳，红发=红雷/红瞳，无字幕无台词，观众靠颜色读局势。
- 前段两人轮流单人秀：能力特写 → 人脸特写 → 全身走位，先把两个角色分别「卖」一遍，约四分之一处才同框开打。
- 升级阶梯清晰：对掌爆光 → 隔空打飞 → 近身缠斗 → 红发掐脸 → 烟尘爆点（全场最暗一帧做呼吸）→ 白发觉醒巨爪 → 城市级光束与蘑菇云 → 白发力竭特写（紫色泪痕）→ 红发扶住他，切黑出厂标。
- 经验：无台词打斗靠「色彩编码+升级阶梯+爆点后留一帧喘息」；结尾不分胜负，用「代价特写」收，结局位让给品牌。

## V10 LIBTV 一张图生成角色PV教程（73秒）
- 版式：上半 PV 窗口，下半左源图、右提示词全文滚动；右上角常驻小字「提示词：教程在24秒处」——延迟满足钩子明牌。
- PV 本体（学妹版）：1秒级局部特写轰炸（耳机、徽章、鞋底飞踢、眼睛超近景），拼贴式档案构图定格收尾；学姐版同公式再证一遍。
- 教程段字幕逐步：「这种PV效果适合用在新角色宣发」「角色图最好带上背景，这样AI会学习背景元素添加到PV里面」「在libtv里选择生图功能，输入这段提示词，模型选择sd5.0lite，比例3比4」「点击生成就能得到我这张图啦」「接着选择生视频」——每步只释放一步。
- 结尾：双 PV 高光回放 + 「我们下期再见」，用成果回放代替总结。
- 经验：教程片的信息释放顺序 = 用途 → 双案例背书 → 唯一诀窍 → 参数 → 成果回放；把「方法在第X秒」写在脸上反而锁住留存。

## V12 窥视镜头去AI味教程（73秒，竖屏）
- 点题：「这些AI画面之所以有电影质感，关键根本不是那些复杂的提示词，而是窥视镜头与前景遮挡的巧妙组合。」「窥视镜头不是炫技，它能制造偷拍感、旁观感，瞬间拉满故事性。」
- 方法一 物理窥视遮挡：「很多人最大的问题是，AI画面像上帝视角；但真实世界里，我们都是从角落窥看。」窗框后偷拍=告诉观众摄像机在窗边，在拐角处拍摄，自带悬疑感；石缝后窥视机位超真实。操作：提示词中强制加入前景层（栏杆、窗台、前景岩石遮挡虚化），再配合低角度前景虚化，画面立刻有层次。
- 方法二 氛围窥视强化：物理遮挡是在前面放一个东西，氛围遮挡是空气里有东西——雨雾让空间有厚度，林间尘埃光束让光线有了路径，纱帘后光斑诗意又真实；提示词加 rain、fog、dust、雪花前景、fog 营造氛围感、光斑等带颗粒感的词。「重点不是特效，而是让空间被看见；当光线有了路径，画面就会变成有厚度的影像。」
- 金句收尾：「AI最大的问题不是不真实，而是太干净。只要你给它一点窥视遮挡、一点空气干扰，它就会从摆拍画面变成真实镜头。」
- 经验（对咱们最实用的一条）：写剧本/分镜时给每个镜头指定「摄像机藏在哪」和「空气里有什么」——前景遮挡物 + 介质（雨/雾/尘/光斑），是去AI味、加故事性的最便宜字段；恐怖题材（巴士段）天然吃窥视机位。

## V15 郭导「时间戳法」（104秒，白板课）
- 讲者身份（画面字幕）：郭导，独立导演、AIGC导演、青禾文化创始人。标题：告别AI视频监控感，时间戳法让画面秒出电影感。
- 核心区分：监控感的画面说的是「这段时间发生了什么」；电影感描述的是「时间本身长什么样子」。
- 方法：同一段素材、首尾帧不变，用带时间张力的词（肉眼难以可见的速度、纵身一跃来到楼层中间、在空中短暂凝滞之类）把时间戳描述词切分进不同时间段，再叠上景别内容和镜头，画面就有了电影感而不是监控感。
- 经验：分镜/提示词的时间轴不要只排事件，要给每一段指定「时间的质地」（快得看不清、凝滞、缓慢坠落……）——这与 V02 的速度曲线是同一件事的两种说法：节奏写在时间里，不写在事件里。
