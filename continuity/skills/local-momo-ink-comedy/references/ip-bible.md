# IP 圣经 · 墨团团（MoTuantuan）

> 本文件是贯穿所有集数的角色与世界观硬设定，任何一集都不得违背。视觉参考：`墨团团_原型设定_简洁标注_v02.png`、`墨团团_四臂魔王_简洁标注_v06.png`。

## 角色：墨团团（默认「萌犬形态」）
- **外形**：巴掌大小、通体纯黑油亮的圆滚滚短腿小黑狗，由活体液态墨水构成；黑曜石果冻质感，表面浮动细微金色星尘微粒；大圆头、无脖、短足，两只软垂小圆耳，银灰色大眼睛，身后一根毛笔尖短尾巴。
- **标志配饰**：脖颈戴金属链条，挂**青铜小铃铛 + 红色流苏**。铃铛是本体标志——无论变形成什么形状，铃铛都在；也是情绪开关（得意时铃铛乱晃）。
- **性格**：死要面子、极度自恋、起床气暴躁、傲娇；喜欢装凶但经常破功；身体比脸诚实（尾巴/耳朵出卖情绪）。
- **招牌动作**：歪头打量（思考）、尾巴失控狂摇（得意时）、两只后脚直立站起挺肚皮、两只前爪叉腰、嘴角单侧上挑露出坏坏的得瑟歪嘴笑。
- **声音（如有）**：短促稚嫩的哼唧/嘿嘿偷笑/呼噜声/喷嚏声，无完整人类语言。

## 双形态系统（本 IP 核心变身）
1. **萌犬形态（默认）**：巴掌大圆滚滚小黑狗，日常卖萌、被追、逃跑都用这个形态。
2. **四臂魔王形态（爆发/被逼急）**：纯黑水墨躯体带金色星尘微粒；**四只肌肉发达的粗壮手臂配锋利黑曜石利爪、背负暗红蝠翼、头顶两只巨大弯曲盘角、额头金色符文**，颈戴粗金属链悬挂**雕刻全视之眼的大铜铃配红流苏**；体型变大，视觉压迫感强。三种官方经典表情：
   - **威吓**：龇牙低吼、四臂张开、铜铃发光——看起来很凶。
   - **露怯**：看到强敌/真危险瞬间怂掉，翅膀缩起来、角耷拉、眼神飘。
   - **强撑**：明明害怕还硬撑，腿抖、强装镇定、墨汗珠直冒。

### 变身规则（喜剧向，必须遵守）
- 变身要**「先膨胀→再定型」的夸张过渡**，不能瞬移；每次变身至少展示 1 秒过渡动画。
- 变身后力量强，但更容易出洋相：大肌肉+小脑瓜=莽撞，经常「只变一半」——只长出四只手忘了角、只变出翅膀不会飞、威吓到一半打了个喷嚏变回原形。
- 愤怒、害怕、激动都能触发变身；越紧张越容易变出半成品。
- 魔王形态下铃铛依然在，是"这是墨团团"的锚点。

## 墨水能力（墨化系统，参考毒液）
- **局部变形**：大拳头、巨掌、触手、弹簧腿、弹弓臂、滑翔翼、降落伞（摊成一块布）、雨伞/盾牌。
- **整体变形**：变成一滩墨水贴地潜行、缩小成墨滴钻缝、拉长成面条、压扁成纸片、充气成气球。
- **分裂**：分出 1–3 个小墨分身，各自独立行动 3–5 秒，用于同时恶作剧/声东击西；分身可以说话（拟声词级别）。
- **伪装**：短暂变成物体（花瓶、篮球、地毯一角），但颜色永远是墨黑，骗不过近看。
- **墨迹物理**：身体可以"断肢重生"，断掉的墨块会变回墨渍，还能被本体吸回去。

## 规则与弱点（喜剧杠杆，必须使用）
- **怕水**：被泼水/淋雨会变淡、瘫软成一团（像蜡烛融化），需要几秒"回墨"恢复。魔王形态被水浇会当场塌缩回萌犬形态——本 IP 最常用的笑点。
- **高温**：吹风机、火源会让墨凝固变硬，动作僵硬（搞笑僵硬态，走路像机器人）。
- **消耗**：拉伸/分裂/变身太频繁会"变淡变累"，需要吞墨补能（喝墨水瓶、吸毛笔，喜剧化进食）。
- **打不死**：只要还剩一滴墨就能重组（会累、会怂，但不会死、不流血）。
- **情绪映射**：开心冒墨泡/墨点四溅；生气身体冒尖刺、触发变身；害怕缩成一团抖、铃铛耷拉。

## 世界观：《墨团团大冒险》· 遗落秘境
- **底层结构**：无边虚空（深邃墨蓝近黑、稀疏星辰、缓慢明灭的光尘）+ 无限漂浮的「现实切片」（每个切片是某个世界被遗忘的一整块现实，边缘柔和破碎化成光尘消散）。
- **团团之家**：虚空中团团长期居住的固定切片——一座浮空岩洞树屋，全开敞空间（**没有门、没有门框**）；露台铺青石板与发光苔藓，中央立着**高 1.2 米的金色椭圆立镜**（雕花木底座、镜面发暖光），左侧有带书本的小木几，右侧有插羽毛笔的木盒；穿过青石板与红花地毯，室内深处靠树桩处是实木大床（浅色厚棉被、床头挂金色铜铃）。
- **访客机制**：新现实切片在远方虚空中显形，与团团之家切片边缘咬合，访客从交界处走进来；离开时切片分离漂远。
- **时间**：每集独立成篇，可连载；对手每集更换。

## 喜剧行为准则（铁律）
1. **永不真正伤害**：所有"伤害"都是弹飞、压扁、被水冲走式的卡通无害化，对手下集还能回来。
2. **自作自受优先**：墨团团的恶作剧必须经常反弹到自己身上（汤姆式惩罚），这样才讨喜。
3. **赢了要得意，输了要认栽**：绝不阴暗、不报复升级、不记仇；认栽时可以对镜头摊手（每集最多 1 次）。
4. **尊重对手**：对手也有完整表演（表情崩溃、夸张反应），不被当道具。
