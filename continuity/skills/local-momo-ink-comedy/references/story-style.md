# 故事风格锁 · 汤姆和杰瑞式叙事

> 每集都必须符合本文件的结构与节奏。这是"猫和老鼠味"的来源。角色名一律用「墨团团」。

## 核心公式（四段式）
每集 30–60 秒，按 **追逐 → 设局 → 反转 → 惩罚** 组织：

1. **追逐（钩子，0–8s）**：开场 3 秒内冲突爆发。对手出现/挑衅/抢东西，墨团团被追或主动追。第一秒就要有动作（不能慢热铺陈），铃铛声先响。
2. **设局（中段，8–30s）**：墨团团用墨水能力（变形/分身/伪装/变身魔王）设陷阱或恶作剧反击。2–3 个递进笑点，每个 8–15 秒。对手的追逐越来越狼狈。
3. **反转（30–45s）**：计划出岔子——陷阱误伤自己、对手意外躲开、新对手乱入、变身只变一半。反转必须"出乎意料但在逻辑内"（观众能瞬间看懂为什么）。
4. **惩罚（结局，45–60s）**：自作自受的报应落到墨团团（或该受的人）身上，或墨团团将计就计反杀成功。结尾定格 pose + 主笑点收尾。

## 节奏规则
- **笑点密度**：每 8–15 秒 1 个笑点/小反转；30 秒≥3 个，60 秒≥5 个。
- **动作 > 对白**：能不说话就不说话。台词只允许：拟声词、简短感叹（"哇！""哎？""呼——"）、偶尔一句点睛。
- **三拍原则**：任何大动作都走"预备→动作→后果"三拍（如：后退助跑→猛冲→撞墙）。
- **停顿是笑点**：危险临头前必须有一个"意识到"的慢半拍（瞪眼→看下方→尖叫→坠落）。

## 笑点设计法则
- **物理喜剧优先**：滑倒、压扁、弹飞、撞墙、被门夹、踩自己设的陷阱。
- **升级法则**：同一个梗必须升级至少一次（被球砸→被一车球砸→被球海淹没）。
- **反差法则**：严肃姿势做搞笑的事；大动作配小结果（魔王形态憋大招，结果只弹出一滴墨）。
- **报应法则（最高原则）**：设局者必须踩自己设的局。墨团团被自己的陷阱整，观众最爱看。

## 变身叙事用法
- 变身魔王不能是"开挂"，而应是"更大的笑点源"：威吓→露怯→强撑三连是本 IP 招牌节奏。
- 每集**至少安排一次**"魔王形态出洋相"（变一半、被水浇塌、威吓打喷嚏、翅膀撞门框）。

## 结局三选一
1. **自作自受**：墨团团被自己陷阱惩罚，对手得意离开——经典汤姆式，多用。
2. **将计就计**：反转后墨团团反杀成功，定格得意 pose——杰瑞式，用于"墨团团获胜"集。
3. **悬念钩子**：结尾埋下一个新对手/新线索（下集预告式），用于连载。

## 禁忌（红线）
- 不流血、不受伤、不死亡、不黑暗化、不恐怖化。
- 恶作剧全程卡通无害；对手被整后必须"拍拍土还能站起来"。
- 不出现现实伤害后果（骨折、进医院、宠物受伤）。
- 温情可以，但必须用搞笑包装（握手言和也要先摔一跤）。
- 不使用抽象/意识流/深沉叙事，本 IP 只做物理喜剧。
