# Script first production gate

## Stop before you generate

- Pause any generation, assembly, redraw, or re-prompt for a beat when no approved script covers that exact beat.

- Treat a script as approved only when the user approved that version or the designated writer delivered it as final.

- Treat a draft, an outline, an earlier version, a summary, or your own reconstruction as not approved.

- Stop at the first uncovered beat instead of generating the covered beats and continuing into the uncovered ones.

- Name the missing beats and the script you need before you do any other production work.

## Check the lock list before you start

- Read the current lock record for the project before you generate anything.

- List the locks that apply to the beats you will generate, including dialogue, plot order, appearance, camera, wind, and any character timing rule.

- Name the camera set for each shot from the lock record, except for a shot the record marks as special.

- Check that each character entrance in the beats fits the timing the lock record gives for that character.

- Do not generate a beat when its lock list is incomplete, and ask for the missing lock instead of filling it in yourself.

## Hand off the writing instead of writing it yourself

- Do not write or rewrite the script when the user assigned writing to another writer.

- Prepare the requirements the writer needs, including the approved locks, the uncovered beats, and the decisions only the user can make.

- Send the requirements to the user for the writer instead of drafting the missing beats yourself.

- Wait for the approved script to come back before you resume generation.

- Record the approved script version you received so the next beats can be checked against it.

## Report the gate with the work

- State the approved script version and the beats it covers when you deliver generated work.

- State the lock list you checked and name any lock that was missing.

- State plainly when you paused for a missing script instead of presenting a partial delivery as complete.

- Do not present a prompt, a plan, or a description as a generated segment.

## Alternatives for better results

- Ask the user to approve a short beat outline before a long script when approval is the bottleneck, so writing effort follows approval.

- Split a long production into approved beat groups and generate one group at a time, so a missing script blocks only its own group.

- Keep the approved script beside its beat list so a later beat cannot be generated from an older version by mistake.
