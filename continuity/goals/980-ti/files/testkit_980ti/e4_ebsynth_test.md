# E4: EbSynth 传播耗时与质量测试（纯 CPU，不用显卡）

目的：测路线 2 的中枢组件——把一张锁定关键帧的外观，按一段驱动视频的运动传播到每一帧。零显存，只测 CPU 耗时和崩坏程度。

## 准备

1. 下载 EbSynth（免费，jamriska 版，官网 ebsynth.com），解压即用，不用安装。
2. 准备一段驱动视频：手机拍自己挥手或转头都行，3–5 秒，转成 PNG 序列帧（ffmpeg 命令：`ffmpeg -i drive.mp4 -vf fps=12 frames/%04d.png`），分辨率压到 480p 以内。
3. 准备一张关键帧：从序列第一帧改一张风格图（比如用墨团团设定风格重绘第一帧），命名 style.png，尺寸与序列帧一致。

## 运行

1. 打开 EbSynth，Style 选 style.png，Video 选序列帧目录。
2. Keyframes 只放第 1 帧，运行 Synthesis，导出全部帧。
3. 记录：总耗时、帧数、分辨率、你电脑的 CPU 型号。
4. 把导出结果合成视频回放（`ffmpeg -framerate 12 -i out/%04d.png e4_result.mp4`），自己看一遍，记三件事：从第几帧开始明显崩坏、崩坏是纹理错位还是形状融化、主角身份特征还在不在。

## 判读（发回数据后由 Muse 做）

- 单帧平均耗时决定这条管线一条 5 秒镜头的总时长是否可用
- 崩坏出现的帧位决定关键帧要密到什么程度（每段要几张）
- 这一步不需要 980 Ti，任何电脑先跑都行，数据同样有效
