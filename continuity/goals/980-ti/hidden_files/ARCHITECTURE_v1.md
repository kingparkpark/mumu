# 全新视频生成模型架构 v1：软件原生生成（Software-Native Generation）

代号：SNG 引擎。立项依据：用户 2026-10-22 明确要求——市面模型只作参考，要创造一个属于我们自己的、全新的、像普通软件一样不吃配置的视频生成模型，并对标 Seedance 2.5 与 MiniMax 最新视频模型的功能面。

## 0. 核心命题：生成 = 编译 + 执行，不是采样

扩散模型的成本公式：像素数 × 去噪步数 × 参数量。每一帧都在重新发明像素，所以必须靠大算力。
软件原生的成本公式：图层数 × 网格顶点数。视频被定义为「资产 + 关于时间的函数」，每一帧只是函数的求值结果。

这条成本曲线低 3–4 个数量级，而且不是理论：游戏引擎在 980 Ti 上实时渲染 1080p 复杂场景、Live2D 在手机上实时驱动虚拟主播、Flash 动画在 20 年前的 CPU 上满屏跑——「会动的画面必须靠大模型逐像素合成」本身是个未经证明的假设。本架构就是要绕开它。

一句话定义：导演把提示词编译成一段可执行的动画程序，渲染器像普通软件一样执行它。写的是一次程序，渲染任意时长、任意分辨率，成本与视频长度近乎无关。

## 1. 导演层（Director）：只写程序，不画像素

- 输入：文本提示 / 分镜脚本 / 参考图 / 台词。
- 输出：镜头程序 DSL（JSON 时间轴）：场景图层、演员实例、动作原语与参数、运镜、特效、声音时间轴。
- 执行者可以是大语言模型（云端 API 或本地小模型）——它只负责「写程序」，算力成本是一次性的、与帧数无关，这是整个架构省算力的根源。
- 台词逐字锁定、剧情顺序锁定天然成立：台词就是程序里的字符串，重渲染一万次也不会改字。这正好命中用户对 Seedance 的三大锁定要求，而扩散模型永远只能「尽量」。

## 2. 资产层（Asset Factory）：一次建模，永久复用

两种角色表示并行：

- 图层傀儡型：单张设定图自动分割分层为部件（头/耳/躯干/四肢/尾/饰品），生成变形网格与枢轴点，得到可摆姿势、可换表情的傀儡资产。
- SDF 液态型（墨团团天选）：角色 = 一组带符号距离场的团块（metaball 原语），形态即参数。液态变形、融化、分裂、长出翅膀和角、变身四臂魔王，全部是场参数的插值与原语集合的切换，由 fragment shader 实时渲染；水墨边缘用噪声扰动距离场得到。分辨率无关，480p 与 1080p 是同一份程序的两次求值。

背景：远/中/近分层 + 视差系数 + 风格 shader（纸纹、水墨晕染、描边）。
一致性：资产以 ID 被引用，同一资产渲染多少次都是它——一致性由构造保证，不是靠模型「记住」。这是扩散路线原理上做不到的事。

## 3. 动作层（Motion Grammar）：动作是参数，不是像素

动作原语库，每种都是带参数的时间函数，CPU 成本可忽略：
- 基础：位移/旋转/缩放 + 缓动曲线族（动画十二原则的 easing、预备、跟随、弧形）
- 形变：squash & stretch（卡通弹性的核心，参数化幅度与相位）
- 二级运动：弹簧-质点积分——耳朵、尾巴、铃铛、红流苏、斗篷自动跟随主体运动，不需要逐帧画，是物理算出来的
- 步态：程序化行走/奔跑/跳跃（足部相位 + 身体起伏）
- 表情：混合参数（眼型、嘴型、眉位连续插值）
- 口型：音素时间戳 → 嘴形参数，与声音同源生成
- 变身：SDF 原语插值 / 傀儡部件集合切换 + 粒子爆发遮丑

复杂动作 = 原语组合，导演只填参数表。动作库可扩展，每个新原语都是一次写代码、永久复用。

## 4. 渲染层（Renderer）：游戏级合成，普通软件级成本

2.5D 合成器：图层深度排序、网格变形采样、SDF shader、GPU 粒子系统（墨滴/火花/烟尘，二十年前的游戏就在老卡上实时跑）、近似光影（投影、描边、晕染后处理）、虚拟相机（平移/推拉/摇移/手持晃动 = 矩阵变换 + 分层视差）。
目标：CPU 可跑、980 Ti 实时 1080p、导出走 ffmpeg；同一程序可出 480p 预览与 1080p 定稿，抽卡选构图变成零成本重渲染。

## 5. 声音层：与画面共用一条时间轴

TTS 配音、音效检索/合成、BGM 全部挂在同一份镜头程序的时间轴上，音画天然同步；口型由同一音素时间戳驱动——不是生成后对口型，是同源生成。解决用户被反复坑过的「没声音/人物不开口」：声音是程序的一部分，不存在丢声道。

## 6. 学习层：让它配得上叫「模型」

纯工具不是终点，以下三件是研究核心，也是真正的空白区：
- 逆向编译：给定参考视频，拟合出它的 DSL 程序（程序合成 / 逆渲染）——把别人的运动变成我们的可复用原语与参数，别人的片子是我们的训练集，且不需要 GPU 农场训练权重。
- 风格包：画风 = shader 参数组 + 笔触/纸纹资产，可从样本图估计、可分发、可一键换装。
- 导演本地化：用「提示词 → 程序」样本对微调小语言模型，最终导演层也能本地离线跑，整机零云端依赖。

## 7. 功能对标映射（待功能清单回来逐项填表验收）

- 文生视频 = 导演编译 + 渲染
- 图生视频 = 资产工厂建模 + 首帧姿态设定
- 首尾帧 = 首末关键姿态 + 原语插值
- 多镜头叙事 = 多段程序拼接，共用资产库
- 运镜控制 = 相机参数（比扩散的提示词运镜精确得多，是真参数）
- 角色一致性 = 资产 ID（构造保证）
- 视频延长 = 时间轴续写程序
- 视频编辑 = 改程序重渲染：只动被改的部分，其余像素级不变、无损、无重抽
- 音频/对口型 = 声音层同源
- 高分辨率 = 同程序高分辨率求值，无重画漂移

## 8. 诚实边界（写在前面，不自欺）

弱区：写实真人、真实光影物理、开放世界任意内容——程序路线先天弱，不假装能打。
强区：卡通/风格化、固定 IP 连载、任意时长、无闪烁、可编辑、实时预览、低成本量产——恰好与用户的墨团团连载业务完全重合。第一代就定位于此，在这个域内目标不是「接近」Seedance，是在一致性、速度、成本、可控性上反超，只在「无中生有发明复杂运动」一项上靠导演与原语库慢慢追。

## 9. 原型里程碑（按序）

- P0：SDF 墨团团在 shader 里动起来——变形、弹跳、甩耳、铃铛弹簧，纯代码，WebGL 即可跑（用户手机都能验证），不依赖任何 GPU 服务器。这是第一个「大进展」候选。
- P1：傀儡资产管线：一张设定图 → 自动分层网格 → 走路/转头/表情。
- P2：导演 DSL v0：一句提示词 → 10 秒镜头程序 → 自动渲染成片（含运镜与切镜）。
- P3：声音层同源：配音 + 口型 + 音效挂上同一时间轴。
- P4：逆向编译实验：拿一段参考视频拟合出可复用动作原语。

现有三条老路线（现成小模型硬压 / EbSynth 管线 / 窄域蒸馏）自即日起降为参考与备选，E1–E3 测试包仍有效（其中的 SD1.5 关键帧能力可被资产层借用），主线资源投向 SNG。
