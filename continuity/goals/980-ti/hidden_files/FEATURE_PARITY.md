# SNG 功能对标表 v1（对 Seedance 2.5 的 49 项 + MiniMax H3 的 45 项）

来源：features_seedance25.md / features_minimax.md（均为官方口径逐项核查）。本表按「用户拿到的功能」对标，不按实现技术对标——同一个功能，扩散靠采样、SNG 靠构造，判定只看用户侧是否成立。

## 一、构造自带，且原理上反超（SNG 的主场）

- 角色/多主体一致性（Seed F14/F15、H3 F11/F12）：资产 ID 引用，同一资产渲染多少次都是它；多主体各引各的资产，不存在特征串扰。扩散是「尽量保持」，SNG 是「不可能变」。
- 时间戳级/区域局部编辑（Seed F24/F25/F27、H3 F15）：改程序里对应时间段/图层的参数重渲染，其余部分逐像素不变。两家大模型最难复刻的第三项，在 SNG 是构造自带。
- 多轮延长与任意时长（Seed F22/F23/F16、H3 F17）：时间轴续写，新旧段共用资产与程序状态；无 30 秒/15 秒上限概念，长视频一致性不随轮次衰减。
- Draft 样片模式（Seed F41）：同一程序先低分辨率求值选构图，定稿同程序高分辨率求值——不是二次推理，不存在样片与成片漂移。Seedance 的 Draft 到 1080P 是重推理、用户已被漂移坑过（见项目记忆），SNG 从根上没有这个病。
- 可复现/seed（Seed F47 存疑、H3 F42）：程序是确定性的，同程序同参数永远同输出，不需要 seed 概念。
- 运镜（Seed F11、H3 F08）：真数值参数（机位、焦距、路径曲线），不是提示词碰运气；可逐帧精确、可复用、可编辑。
- 台词与剧情锁定（用户硬约束）：台词是程序字符串，对白内容、顺序、归属全部确定；模型层主动抑制随机字幕（Seed F42）在 SNG 是默认状态——没有字幕资产就不会出现字幕。
- 输出规格（Seed F35–F40、H3 F26–F29）：时长任意整数/小数、画幅任意、分辨率与帧率是求值参数（24/30/60fps 同程序重采样），MP4 导出。

## 二、机制不同、用户侧功能等价（靠导演层+资产层实现）

- 文生视频（F01 对）：导演把文本编译为镜头程序。开放度取决于动作原语库与资产库的丰富度，第一代限卡通域。
- 图生视频/首尾帧（Seed F02/F03、H3 F02–F04）：图 → 建资产/定姿态；首尾帧 = 首末关键姿态 + 原语插值。
- 多镜头叙事与时间戳分段控制（Seed F09/F10、H3 F07）：多段程序拼接 + 时间轴分段参数，控制粒度比提示词式更细。
- 一镜到底（Seed F13）：单段长程序 + 相机路径，无需拼接。
- 音频全套（Seed F29–F34、H3 F19–F24）：TTS 对白、音效、音乐挂同一时间轴；对口型由音素时间戳驱动嘴形参数（同源同步，不是联合采样，但用户侧同步效果等价）；多语言能力 = TTS 的语言覆盖（中文/英文等主流语言现成，11 种全覆盖需逐个接 TTS）；立体声为混音层能力。
- 参考音频驱动节奏/音色（Seed F32、H3 F13/F24）：音频分析出节拍与音素时间轴后驱动程序参数；音色参考 = 选定 TTS 音色资产。
- API 工程面（Seed F43–F49、H3 F35–F40）：异步任务、回调、素材注册引用，均为普通软件工程，无难度。
- 快速变体（H3 F33/F44）：SNG 本身就是实时级，不需要加速变体；低清预览即天然快速档。

## 三、难追（研究项，按难度排序）

- 参考元素分解理解（Seed F17/F18–F21、H3 F05/F09/F14）：给任意图/视频/音频，用自然语言逐份指定取其中的构图/动作/运镜/音色。SNG 的对应物是「逆向编译」（P4）：把参考拟合为资产与程序参数。目前只能覆盖结构化程度高的参考（姿态、运镜、节奏），开放语义理解是最远的一项。
- 白模/绿幕参考的物理响应重渲染（Seed F07/F08/F26）：白模定空间与机位在 SNG 可行（灰模本来就是程序的输入形态），但「按新环境重算衣物/头发/光影物理」需要布料与光影近似的积累，中期目标。
- 任意帧引导（H3 F10）：任意中间帧定姿态 = 在时间轴任意点加关键姿态约束，机制可做，约束求解的自然度待验证。
- 画面内文字渲染（H3 F45 社区口径）：刻意设计的文字（招牌、标题）以资产渲染反而清晰可控；画面里 incidental 的环境文字生成弱。

## 四、承认的弱区（不假装）

- 写实真人质感与真实光影：程序路线的先天弱区，第一代不进入。
- 开放世界任意内容的「发明」能力：扩散的通用性来自大数据，SNG 的通用性来自原语库与资产库的生长速度，先慢后快，前期靠聚焦卡通 IP 域换取可用性。

## 结论

94 个对标项里：约三分之一 SNG 构造自带且反超，约三分之一机制不同但功能等价，约六分之一是研究项，剩下是承认的写实弱区。而用户的主战场（固定 IP 卡通连载）恰好落在前两类里——这就是这条路线成立的依据。
