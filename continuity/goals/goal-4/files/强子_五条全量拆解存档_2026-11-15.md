# 二、逐条剧情链（每一步都是被上一步逼出来的）

## Q1 过溪筑坝（危机线）
命题：过溪涨水，回不去也过不去，人困在河心石头上。
链：躲石头后站住（只是能站，两边还是过不去）→ 卸包减负 → 发现漂木堵满挡板反而更危险（第一个被现实判掉的直觉）→ 先合一道口，南面腾出来施工 → 水退清软泥 → 锚住硬岩（「这一段才算真正有根」）→ 块石压重、模板锁死、浇实一段（先回南岸）→ 人回来了，可水全冲北边，南段白做一半（问题换边）→ 放一部分水回来给北边腾地方 → 水路换过去，北边同法施工，大股水走主闸、岸边只分一小股 → 「这回整条河才算管住」→ 凝固后验收：闸框接缝没松、顶上连成一体（「两边才真是一整座」）→ 开主闸泄劲、撤临时挡板、闸口拦污网先卸水的劲 → 问题域再换：水能过了，人渴着——浑水沉沙→沙层活性炭过滤→消毒→头段水放掉→「现在人能过，洪水有地方走，这边也有干净水了」。
特征：同一条河做了三遍（南、北、净水），每遍解决一个新问题域；判分句永远落在验收之后。

## Q2 营地雨洪（危机线）
命题：泥水一直往营地里灌。
链：沙袋压正面（水从两头绕——当场判掉）→ 挡不住就先开个出口（先保命级处置）→ 出口通了，可小沟一会就让泥填死（判掉）→ 诊断拍：他走上去看清——水是从上面整片坡汇下来的（全片转折，镜头跟着他走）→ 必须在水进营地之前截住 → 线找对了，可人工慢慢挖雨等不了（判掉人工）→ 上挖机（规模升级的理由是时间，不是炫）→ 沟截住水，可泥和树枝全进来了（新问题）→ 分离：格栅拦树枝草团、沉沙池压水速、第一池留石子和粗沙（「水得一层一层往下过」）→ 一个出口吃不下，分两路绕营地 → 弯位给够宽度 → 沟挖出来还不算：底要防冲、外弯要压（耐久判据）→ 路不能断：涵管接通，上面照样进出 → 外水绕开后，营地内部自己落的雨还得单独排（问题域再缩小一层）→ 全收进集水口 → 八台泵并联进排水站（水靠自己过不了低口）→ 「这套雨洪系统才算接完整了」。
特征：诊断拍占全片转折位；升级顺序是先分流、再分离、再耐久、再内部、最后动力——每级都是被上一级的副作用逼的。

## Q3 戴森球（私活线）
命题：网友评论让他造戴森球——「没毛病，这活我接了」。
链：先建原料工厂（采矿→母机与岩体锁一体→切削封闭输送→分选熔炼→统一规格金属原料）→ 原料、采矿、制造连成工业母站 → 做采能薄膜标准卷材 → 框架散热姿控装成标准采能单元 → 第一台先上测试架展开（小试先行）→ 原型发的电送回母站，启动第二批生产线（系统开始自己养自己）→ 三线齐开，单元按同一规格量产 → 建质量投送轨道送材料上天 → 部署舱到轨道区，先放几台做展开测试（又是小试）→ 照基准一块块接满轨道 → 开盒验展开、统一校时测距控间距 → 电越多废热越多：汇流节点先展散热，再接电、稳压储能 → 放检修机器人，坏单元能换回来（为长期运行留口）→ 中间铺满再补南北两头 → 各区统一校位，「一整层完整的采能环」→ 能量送外层接收站转换、进主电网、接深空船坞收尾。
特征：私活线没有灾难，发动机是「上一级的产出是下一级的入场券」；两次小试（测试架、轨道试放）是全片的信任锚。

## Q4 雷暴避难所（危机线）
命题：雷暴来了，草原上没有能躲的地方，身边还有一条狗。
链：先挖个低点（光蹲下不够）→ 安置狗「你在这稳住」→ 底下全是硬层，先敲开（不然坑下不去）→ 土泡软，再挖就塌（判掉深挖）→ 这圈土先撑住 → 排水：水先收进坑再引出去，底下才能接着坐 → 临时撑着还不算，拱架排排接过去，土压往两边散 → 这种壳最怕板缝进水，压严 → 主体埋住了，可门一眼通到底，风雨全冲进来（新问题域：门）→ 入口拐弯、两道门错开，外水先在门洞截住，漏进来还有集水坑 → 密封之后空气不循环：进出两根管不能混 → 风雨进不来、气也能换了，可铁皮冰得扎手，里面待不住（新问题域：温度）→ 隔热层隔开，热不被铁皮吸走 → 有光有暖风、湿气能排，「这里面才真正能待人」→ 家具：放倒能坐能躺、工具吃的收下面、过道不占 → 结尾：外面还在打雷，里面暖和干燥，他跟狗吃饭睡觉。
特征：问题域迁移最清楚的一条：地形→结构→防水→门→空气→温度→生活；每次升级都由他亲手摸到、看到（摸铁皮冰手）才触发。

## Q5 箭矢量产（私活线）
命题：赤壁大战在即，丞相把储备箭矢的活交给他——「没毛病丞相，我接了」。
链：料不少，但规格太乱（诊断先行）→ 先搭场地：修水道、上发电机、主电接稳再接机器 → 原料这边进、成品那边出，先把路理顺 → 烤着掰直木杆：一根一根到天黑也做不完（判掉手工）→ 上连续调直定程线，木杆进去箭杆出来 → 拿几根试机，直度和粗细稳了再正式放量（小试）→ 箭杆能连续出了，箭头跟不上：分锻逐锤打，速度供不上箭杆（瓶颈转移）→ 箭头形状还得统一：上封闭式连续锻条线 → 重设备先落钢底座，模具送料中心对齐 → 先用一段料试模，成型切边合格再连续送料（小试）→ 箭杆箭头都有了，组装又成慢活 → 钻孔装箭头、开尾槽粘箭羽，一支支做还是太慢 → 各道工序拆开排成一条线，箭才能连续往前走 → 先对夹具中心（不然箭头箭杆接不到一条轴线）→ 一支样箭校准压装深度和三片羽的位置 → 连续装配：歪的单独返修，合格的直接进架（品控）→ 散箭越积越多，靠人一支支数，前面线都得停（瓶颈再转移到仓储）→ 先定量再捆扎、箭数直接装车 → 捆扎法：前后各扎一道、箭头套住，搬运不散 → 入库纪律：不落地、不贴墙、上下通风防潮 → 丞相验收「箭已备妥」→ 出库设计兑现：库门一开，箭顺着栈道直送阵位 → 结尾反转：箭一面接满又转一面——「中计了，诸葛亮竟用草船取我箭石。好一个草船借箭。」
特征：瓶颈转移教科书：原料规格→调直→箭头产能→组装→计数仓储→出库动线，每级都先量出「慢在哪」再上设备；结尾用一个历史梗把整条工业链反杀，笑点长在严谨上。

# 三、表达方式（文案语法）

1. 旁白是第一人称现在时的工作口述，不是解说：每句只干一件事——报正在做的动作、报刚发现的约束、报下一步的理由、报验收结果。五条里没有一句世界观介绍、没有一句抒情。
2. 句式骨架（按出现频率）：
- 命题句：「过溪时突然涨水了怎么办」「泥水一直往营地里灌怎么办」「雷暴来了，这周围没有能躲的地方」——开场3秒内把灾难说成一个具体问题。
- 接单句（私活线）：「没毛病，这活我接了」「没毛病丞相，我接了」——先答应，再开工，不讨价。
- 先手句：「先躲到石头后面」「先把包卸下来」「先把正面这股水压住」——永远先有一个最便宜的动作落地，再谈方案。
- 判掉句：「不行，这股水已经走不回去了」「光靠这一排挡不住」「可这点小沟一会就让泥填死」「一根一根烤着掰，到天黑也做不完」——失败必须说清死因，死因就是下一级的设计要求。
- 不然句：「不然站都站不稳」「不然泥沙进了池子也沉不住」「不然这个坑根本下不去」——每个关键动作都挂一个看得见的后果。
- 诊断句：「看清了，这些水都是从上面这片坡往营地里汇」「料不少，但规格太乱」——先看清，再动手；诊断是全片转折点，单独成句。
- 分层句：「水得一层一层往下过」「前面沉大的，后面留细泥」「各道工序拆开排成一条线」——复杂系统只用一句人话讲清分工。
- 判分句（才算语法）：「这一段才算真正有根」「这回整条河才算管住」「这套雨洪系统才算接完整了」「这里面才真正能待人」——「才算」只出现在实测通过之后，一集最多两三处，全用在刀口上。
- 收束句：不抒情，报状态：「现在人能过，洪水有地方走，这边也有干净水了」「外面还在打雷，这里暖和、干燥，吃饭也能睡觉」。
3. 数字与规格只在能判分时出现：八个泵孔、统一规格、一层一层；从不报无用参数。
4. 语气：平、稳、不笑场；幽默感来自规模与处境的反差本身，他从不点破。

# 四、镜头语言

1. 四种机位轮转，全片无第五种：
- 自拍近景：只用于开场命题、诊断转折、验收判分三类时刻——他对着镜头说话，观众是甲方。
- 第一人称手持（绝对主力）：双手和工具占满画面下半部，观众的手就是他的手；施工、测试、验收全用它。
- 固定远景/全景：只在规模兑现时出现——整座坝、整条生产线、完整采能环——一次兑现一次，不滥用。
- 机械视角：挖机驾驶室、传送带正上方、轨道部署视角，短暂借用，强化「系统在运转」。
2. 镜头永远在工位上：切点跟着工序走，一个镜头一个动作；平均镜头2到5秒，全片百余个切点，没有一个空镜抒情。
3. 自然感来源：阴天散射光为主、泥水汗渍不躲、设备有磨损、天气是真的在下雨刮风；画面里永远有正在发生的事（水在涨、雨在下、线在走），没有一秒是摆拍站桩。
4. 发现与验收都用镜头证明，不用台词宣布：判分句说出口之前，画面先给出证据（水位退了、接缝没松、箭成排进架）。
5. 结尾镜头固定配方：系统全景（远）→ 他本人回到画面里用上成果（喝水、吃饭、睡觉）→ 结束。先证明系统，再证明生活。

# 五、他怎么了解问题、怎么解决问题（方法总纲）

1. 先活下来再解决：第一动作永远是最便宜的保命/止损（躲石头、压沙袋、挖低点），不追求一步到位。
2. 先看清再动手：动手做大之前必有一拍诊断——走上去看水从哪来、摸铁皮凉不凉、量规格乱不乱。诊断结论单独成句，是全片转折。
3. 小试先行：第一台先上测试架、拿几根先试机、先用一段料试模——小规模验证通过才放量，失败因此又小又早。
4. 瓶颈驱动升级：不预设大方案；每一级方案只解决当前最紧的约束，方案的副作用就是下一级的题目（堵住正面水从两头绕、截住水泥沙又进来、密封了空气又不循环）。
5. 判分靠实测：每级完工必有一次当场测试，现实给分；「才算」只在实测通过后说出口。
6. 规模是被逼出来的：上挖机是因为雨等不了，上锻条线是因为逐锤供不上——规模升级的理由永远是时间和瓶颈，不是炫技。
7. 系统收尾要闭环：水要有去处、电要进电网、箭要能出库；最后还要留维护口（检修机器人、返修工位、集水坑）——他交付的不是一个物件，是一套能自己转下去的系统。
8. 人的落点：系统再大，最后一个镜头永远是他用上成果过日子。
