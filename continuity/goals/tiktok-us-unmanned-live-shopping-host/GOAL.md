# TikTok US unmanned live-shopping host

Goal ID: goal_a71d354ec4e3
Goal slug: tiktok-us-unmanned-live-shopping-host

## Description
Build an unmanned TikTok US live-shopping host that answers comments automatically, knows its products, and performs like a trusted US presenter. It runs lightly on the user's own computer through TikTok LIVE Studio, using DeepSeek for replies and a real-time digital human for gestures and product display. The current direction is a low daily-cost sample to prove the effect before any larger spend.
