## Description
A dedicated short-video script series starring kittens Apai and Aman, set in a Cat House shop in a space-time rift town. It uses Gintama-style IP parody — recognizable traits and moves on animal stand-ins — as its core engine. Scripts must open with a strong hook, earn laughs visually as well as in dialogue, and leave an open point for comments.
