# Launch Radar — a token-radar-01 entry

A program plus the static dashboard it writes. The program reads the sealed
DefiLlama snapshot, fits a comparables model on the snapshot's own live-token
protocols, ranks the pre-token protocols by implied launch value, and gives
every ranked protocol a farm plan with dollar costs and times.

## Run it

```
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```

Node 22, standard library only, no network. It writes `board.json`,
`data.js`, `dashboard/`, `screenshots/` and `dossier.json` into the output
directory, and refuses to write anything if the board it built fails the
gate's shape.

## The model (lib/model.ts)

- Fit: least squares of log10(market cap) on log10(TVL) over every live
  protocol in the snapshot with a positive market cap (n = 128 on this
  snapshot; one further record carries a −1 sentinel instead of a cap and
  is excluded).
- Implied value = comps base × category multiplier × growth multiplier ×
  maturity multiplier. The category multiplier is the category's median
  actual/fitted ratio, shrunk toward 1; growth uses the 7-day TVL change
  clamped to −50%…+100%; maturity rewards time run with no token.
- The board covers the snapshot's whole watchlist plus every other rankable
  pre-token protocol. Wrapped, staked or bridged products of tokens that
  already trade (WBTC and its kin, by the field guide's own watchlist rule)
  and versioned pools are set aside, not ranked; live-token protocols are
  shown at the market's own values in the dashboard's Live view.
- Farm plans are generated by category rules from each protocol's own
  record (TVL-sized capital, chain-priced gas, age-set holding window), and
  each plan's last step totals its gas cost in dollars.

The dashboard's Model & method page prints the fit's diagnostics (n, slope,
intercept, R², median absolute error) recomputed from the snapshot on every
run, so the page cannot quote a number the code did not produce.

## Layout

- `main.ts` — the entry program.
- `lib/model.ts` — snapshot parsing, the fit, the board, the farm plans.
- `dashboard/` — the static page (index.html, app.css, app.js); renders
  `../data.js`, works offline, no external references.
- `screenshots/` — the board, one protocol's detail view, a filtered board.
- `vendor/makefun-board.ts` — make.fun's dossier library, carried byte for
  byte as the kit ships it, so the dossier written here is the one the
  scorer rebuilds.
