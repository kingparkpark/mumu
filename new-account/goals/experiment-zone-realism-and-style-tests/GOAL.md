# Experiment-zone realism and style tests

Goal ID: goal_f5f6d8dd6df6

## Description
Ongoing experiment-zone tests to learn which ultra-realistic and stylised treatments work, using the werewolf and other subjects in short films the user judges. Nothing moves into the werewolf production session until the user says so, and each test is judged for realism, continuity, and handling.
