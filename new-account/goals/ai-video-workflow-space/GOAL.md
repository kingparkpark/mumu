# AI video workflow space

Goal ID: goal_769ae5fb1b6f
Goal slug: ai-video-workflow-space

## Description
A Chinese-language AI video workflow space with five switchable zones, rebuilt as a Muse-specific BeefTV-style node canvas with auto-derived status, a preset nine-node production chain, and an execution queue that opens each model's generation entry. It uses the 205 real prompts from the apimodels muse-video-prompts repository, supports editing, saving, export and copy, and demonstrates the flow with a sample idea.
