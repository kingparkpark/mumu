# 选题与剧本内容辅助 — 助理自用

本技能供助理在与用户讨论「下一条拍什么、这一集写什么」时使用：出选题、评估选题、把选中的题发展成内容框架。全部结论来自博主调研语料（见语料索引），引用时以原文为准，存疑回查，不凭记忆扩写。

**分工界线**：正式动笔写大纲与剧本走 comedy-script-craft（发动机菜单、14 条规律、台词工艺、12 项自检都在那本，本技能不复述）；分镜归《分镜写作规范》；世界观与资产归《猫事屋_系列资产设计总册》，新设定必须有出处（见 script_canon_provenance_check）。本技能只管上游：选题与内容框架。

**账号现状锚点（用前先核 MEMORY 最新状态，不凭本条）**：猫事屋正传为主线（Ep1 已上线、Ep2 在产、Ep3 以 v3 为讨论底本），夹缝小镇边角故事为衍生线；墨团团暂搁置。登场纪律：每集正式登场新角色宜少，已登场可返场，未登场只许无台词角落彩蛋；恐怖画风角色不得连排，须先有独立恐怖篇；新提的乱入角色只是库存，未经用户批准不进已锁定集数。

## 一、选题工作流

### 1. 先分清用户在哪个模式

- **灵感模式**（用户说没灵感、说不出想要什么）：给一批题让他砍，不给成稿、不给公式化拆解。每题一行：题眼＋发动机＋第 0 秒钩子＋互动件。数量宁多勿少，他砍掉的永不再推。
- **评估模式**（用户自己出题）：用第二节六问逐条过，当场指出哪问塌了、塌了怎么补，补不出就直说这个题弱在哪。
- **发展模式**（题已选定）：进第三节，把题发展成内容框架，再交 comedy-script-craft 动笔。

### 2. 选题从哪来（五路，按产出率排序）

1. **发动机反推**：从 comedy-script-craft 发动机菜单挑一台没用过或没用够的，乘猫事屋现成槽位（柜台、委托、相亲、镇上日常）生题。发动机先行是实证里最稳的出题法。
2. **变量槽轮换**：已验证过的发动机换零件不换骨——来访者换人、规则换一条、流程换一套（规律 12）。正传续集优先走这路。
3. **乱入库存**：`夹缝小镇_乱入角色表`里未登场的角色，按「设定自带冲突」挑（agenyō 05 的教训：来访者的诉求要与日常相撞，尝试姿态要能逐级降格）。注意登场纪律与恐怖不连排。
4. **全民经验＋观众日历**：选题优先全民共同经验（规律 9），发布时间跟观众的生活日历走（开学、过年、发工资、降温）。
5. **边角补世界**：衍生线专用——小镇任何角落的小故事，标准是惊呆、有趣、足够癫，镇民对怪事理所当然；两猫家务温情路线已否决，不许再提。

### 3. 选题评估六问（每问都要有具体答案，答不出即弱题）

1. **钩子型**：第 0 秒的钩子是规则、命题、状态、对照构图中的哪一种？是「发生了一件大事」式事件钩的，先改再议。
2. **发动机**：哪台发动机驱动全集，一句话说得出吗？只有事件罗列没有发动机的，毙。
3. **画面笑点**：不靠对白的笑点至少一个，具体是哪一拍、什么画面？全靠台词逗的，毙。
4. **互动件**：观众能竞猜、站队、接龙的东西具体是什么、埋在哪一拍？「希望观众评论」不算答案（用户实证否决过无赌注的留白）。
5. **制作可行性**：按生成端三老毛病预检——初始状态能不能一张首帧图锁死？动作里有没有要全程归属一致的道具（有就预备段首重述与数量账）？有没有高难物理卡点（坠落半空接类，有就降实现难度或拆两拍）？选题阶段避开，比成片翻车便宜。
6. **红利与纪律**：借的梗过红利三问了吗？登场人数、恐怖连排、与前集的符号语义推进，对照账号现状锚点过了吗？

### 4. 砍题呈现纪律

批量出题时每题只给一行半：题眼、发动机、钩子、互动件各一句，**不写小剧本、不写分镜**——题的阶段写太细会污染判断，也违背用户「要灵感不要公式」的定调。他砍剩的再进发展模式。被砍的题记下来，同题不再重推（换发动机或换槽位的新题除外）。

## 二、44 卡增补手法（14 号逐帧之外，选题与内容层可用）

- **柜台三段式**（战五喳）：期待→落空→加码的柜台节奏，猫事屋柜台戏的现成骨架。
- **闭环话术**（累子）：一句话绕回开头形成闭环，当单飞句的设计模板。
- **群像托一对**（房东的肥四）：群像配角各有功能，只为托一对可嗑关系——柯柯×富江线的排布参考。
- **基本功不换、宇宙轮换**（周小闹）：同一套本事换委托宇宙续命，与变量槽轮换同向，排长线时用。
- **冷面导演×荒诞主体**（柯铭）：拍的人越正经、被拍的越荒诞，反差越大；对生成端意味着表演负向锁要更狠。
- **最像猫标准**（猫子柒）：热评定性「最像猫的，其他像披着猫皮的人」——两猫的动作与反应先过「猫会不会这样」再过「人会不会这样」。
- **仍有效验证**（张离谱 Dreams）：老牌号里唯一被近一年数据证明打法仍有效的，借老打法时优先参考它，其余老号先过红利三问。

## 三、内容框架工作流（题选定后、动笔前）

产出一页框架，六件齐了才交 comedy-script-craft 写正文：

1. **发动机与刻度表**：主发动机一台（副的至多一台）；升级刻度逐级写明（扩围／降级／降格／通胀／轮换零件），每级落在哪个事件上。
2. **第 0 秒钩子**：写出开场那一帧／那一句是什么，属哪种钩子型。
3. **互动件落点**：留白一处、单飞句一句，写明各在哪一拍；单飞句先脱离语境自测一遍（规律 11 的四种造法：名场面句单飞、选项卡站队、共识型标题、双版本对照）。
4. **收尾件**：回落／小刺／暖着陆＋一笔小账／双版本／符号动作，五选一写明；系列符号动作本集是正用、反用还是缺席兑现，与前集的语义推进写清（规律 13）。
5. **人查与物账**：出场名单对照登场纪律；关键道具列数量、位置、归属（给后面剧本的逐拍重述与分镜的段首状态重述打底）；新设定逐条标出处，无出处不进框架。
6. **时长预账**：按节拍数×实测密度（一次生成约一拍、成片约 10–15 秒）估总长，台词按字数÷4.5 字／秒先算再排，禁止先定总秒数再塞内容。

框架交付时附六问自查结果（第一节第 3 条），哪问是勉强过的，明说，不藏。

## 四、评论与分享设计速查（出自评论区机制研究）

- **笑、点赞、评论、关注是四个不同的动作**，触发点不同：选题阶段只对「评论」做专门设计，其余靠内容本身。
- **句式可模仿＝评论量**：能被观众套着造句的模具（子涵体式）是最强的评论发动机；单飞句设计时优先往「观众能接下一句」的方向写。
- **集体认领接龙**：给观众一个可以认领的身份或罪名（告密者式），评论区自己会滚起来。
- **粉丝暗号**：系列符号动作与固定句的评论区回报在这里兑现——观众刷暗号即免费续作广告，故符号要规划语义扩展路线、不许硬凑口头禅（项目纪律）。
- **留白竞猜**：关键信息不给看、只给反应与后果；留白必须有赌注（有可猜的答案、有揭晓），无赌注的留白用户已实证否决。

## 五、禁用与诚实边界

- 过期打法禁用清单与红利三问见 comedy-script-craft 第六节，本技能同样执行。
- 本技能是助理的参谋工具，不是战绩：用它出的选题被用户否了，就是题不行，不许拿「实证规律」压用户判断；规律与用户直觉冲突时，先按用户直觉走，再回查语料看规律是否被误用。
- 涉及账号现状、集数状态、已锁定设定时，先核 MEMORY 与总册再开口，不凭本技能里写的锚点当现行事实。
