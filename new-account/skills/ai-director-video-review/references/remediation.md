# 返修方案

## 选择最低成本路径

- 剪辑规避：问题位于非必要头尾、重复动作或可删除停顿。
- 后期修复：文字、Logo、水印、局部遮盖、声音、电平、简单色彩或稳定问题。
- 局部重生成：短时间的人脸、手脚、物体交互、纹理爬行或单一动作损坏。
- 整镜替换：主体身份、产品结构、空间或叙事在大部分时长持续失效。

## 每个返修包应包含

- 目标片段和建议保留的前后边界。
- 需要锁定的角色、服装、产品、场景和镜头特征。
- 正向约束：明确期望的可观察结果。
- 负向约束：只针对已观察到的问题，不堆通用负面词。
- 方法建议：剪辑、后期、局部重绘、首尾帧约束或整段生成。
- 验收点：返修后需要重新确认的 2–4 个可见条件。

## 导演诊断对应的返修

- 人物运动失真：把动作拆成起步、承重、接触、推进和停止，明确脚底、重心与衣发的时间关系。
- 景别或机位关系不成立：先说明镜头要交代空间、动作还是情绪，再调整人物占比、视点、拍摄距离、背景层次和运动空间。
- 运镜显得机械：补充运镜动机、跟随延迟、加减速曲线、视差和停点，避免只写“电影感运镜”。
- 画面很平：优先建立主体与背景的明暗、色彩、距离或遮挡层级，不默认用更浅景深解决。
- 情绪不成立：补足视线对象、触发事件、反应停顿、身体紧张度和情绪递进，再决定是否切换景别。

返修建议应落到可观察结果。若平台无法直接控制焦距、光圈或运动曲线，将专业参数翻译成画面关系和动作描述。

## 提示词模板

```text
保留：{稳定参考帧中的角色、服装、场景、构图与光线}
动作：{清晰描述动作起点、接触、运动路径和终点}
约束：{针对问题的稳定结构与连续关系}
避免：{本次实际发生的换脸、粘连、乱码或融化}
首尾：从 {起始状态} 自然过渡到 {结束状态}
```

不要承诺某个平台或模型一定支持某种控制方式。用户未说明生成工具时，用供应商中立语言给方案。

## 失败图谱路由（v2.0 新增，据 Seedance failure atlas 与本项目实测）

| 症状 | 机制诊断 | 首要修复变量 |
|---|---|---|
| 群像动作同步 | 同框人数过多＋单位动词调度，模型把群体渲成一个有机体 | 拆分生成（同镜只留少数人同时动作）或逐人状态差异写法；禁止只加"不要同步"字样 |
| 屏幕方向/对峙方向翻转 | 轴线未锁定 | 在提示词与圣经中声明屏幕方向与对峙轴线，或声明有意的轴线重置 |
| 掩体不在敌我连线上 | 只以摄影机视角写掩体关系 | 以敌方视角重写："从威胁源看去，人物全身被掩体遮住，只露出射击所需的最小部分" |
| 续段从计划结尾开始 | 没审母段真实尾态 | 用实测尾帧状态替换计划状态作为下一段起点 |
| 动作重演/未来事件提前 | 已完成节拍未排除、预留节拍泄漏 | 节拍分桶：已发生/本段/预留；本段提示词只写本段桶 |
| 身份随续段漂移 | 连续性来源挤掉了正典身份参考 | 从正典定妆图重新锚定身份 |
| 事件密度过高（一镜多事） | 单次生成装了多个节拍 | 拆段：一代一节拍，复杂接触与多地点优先拆 |
| 特效量级失真（火花雨、大枪口焰） | 效果词无量级锚点 | 正向写量级与范围（"只在命中点一小簇、转瞬即逝"），并定点负向 |

## 重拍经济（v2.0 新增，据 retake protocol）

- 五种裁决：保留 / 后期修 / 只改一层重编 / 同稿重掷（采样运气问题，最多 2–3 次）/ 改稿（同一缺陷在两版重现 = 系统性问题，必须换机制，禁止第三次碰运气）。
- 一次只改一个变量：一条约束、一个参考、一个模式；同改多项的结果无论好坏都读不出原因。
- 动笔前设预算与"够用"标准；预算过半仍无进展，停手换策略（换模式、拆镜、或如实上报做不到）。
- 每版留一行拍摄日志：版号 · 改了什么 · 裁决 · 一句证据。

## 归因先行（v2.0.1 新增，2026-11-21 用户立规）

给任何缺陷开返修方案之前，先归因，三类处置完全不同，禁止混用：

- **A 模型原生缺陷**：在干净输入（最小提示词、无历史模板）下多样本仍稳定重现 → 才允许上约束、锚图、状态链或拆分。
- **B 污染**：缺陷随输入携带的旧模板/旧语料出现，干净输入下消失 → 处置是分割污染源（隔离起草、换工作集、删污染条目），**禁止加约束**——加约束治不了污染，只会叠加负荷。
- **C 过约束**：约束越加、缺陷越重或新缺陷随新约束出现 → 处置是减约束，回到该维度的基线写法。

归因证据标准：同一维度至少 2 个干净样本才可初判，1 个样本不定性。未做过基线测试的能力维度，不得预设"需要约束"；审片报告中每个 major 以上缺陷必须带归因标签（A/B/C/未定），未定者先补测再开方。
