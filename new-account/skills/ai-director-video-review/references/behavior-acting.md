# 表演与行为审查（模块 6 执行标准）

理论来源：角色表演系统（迈斯纳体系）。核心公理：**表演是在压力下的行为，而不是情绪的展示**；群体反应像波浪一样传递，绝不同步。本标准把这套创作知识转成可核查的审片条目。

## 1. 证据产物：逐人动作起止表（强制）

对含 2 名以上人物的动作段落，必须先建表再下结论：

- 采样：动作窗内 ≥8fps（方法见 mvp-workflow 采样协议）。
- 逐人记录关键动作的起始时刻与结束时刻：起身、伏低、开火、停火、转头、移动、操作物件。
- 没有起止表，不得对"同步/不同步"下任何方向的结论；证据不足时本模块标"未充分检查"，不得默认通过。

## 2. 四项必查

### 2.1 同步扫描
- ≥3 名人物在 0.25 秒内起动同类动作（同时起身、同时开火、同时转头）= 同步缺陷 `major`。
- 两人整段动作轨迹近乎镜像（起止时刻差 <0.25 秒且动作序列相同）= `major`。
- 群体对同一刺激的反应时刻应呈波浪分布（先後差 0.2–1 秒、强度递减或变化）；整齐划一 = 假。

### 2.2 冻结扫描
- 重大事件窗内（枪响、爆炸、命中、有人倒下、门被撞开），逐人核查：保持同一姿势 >2 秒且其角色处境无静止理由（不在潜伏、不在瞄准待机）= `major`。
- 背景人物全员冻结 >3 秒 = 环境生命问题联动扣分。

### 2.3 刺激—反应链
- 列出本段全部重大刺激，逐人核查三件事：有没有反应、反应在刺激后多久出现（应有 0.2–1 秒的个体差异）、反应方式是否因人而异（缩头/还击/查看同伴/伏低/僵住）。
- 全员无反应 = `critical`（活人感死亡）。全员同方式同时间反应 = `major`。反应先于刺激出现（预演结果）= `major`。

### 2.4 收尾分化
- 段落收尾帧逐人记录：姿势、朝向、视线对象、手头动作。多人四项全同 = `minor`；若同时伴随 2.1–2.3 任一问题，升 `major`。
- 加分证据（记 note 保留项）：可读的个人节拍，如查枪、换匣、回头确认、看向高处、长出一口气——每人一件不同的事。

## 3. 对话与近景追加项

- **倾听**：搭档说话时听者脸上/身体应有进行中的反应；等对方说完才"开启"反应 = 等待台词，`major`（特写）/`minor`（中远景）。
- **评估瞬间**：重要消息/威胁之后应有消化停顿；匀速即时应答 = 朗诵，`minor` 起步。
- **眼神**：视线须有具体对象且会移动（思考时漂移、扫视、落回）；死鱼眼（长时间锁一点、无眨眼质感变化）= `minor`，特写 `major`。眼睛应先于头部到达注视目标。
- **手头动作**：人物应有正在做的事；全员空手端坐/端枪同一姿势贯穿全段 = 表演空洞，联动 2.2。
- **状态惯性**：重大事件后情绪/身体状态不得瞬间重置；上一拍的余波（喘息、发抖、沉默）应带入下一拍。瞬间"恢复如初" = `minor` 起步。
- **地位与身体**：强者安静少动、弱者烦躁多动是基线；全员同等能量、同等姿态 = 群像无层次，`minor`。

## 4. 糟糕表演图鉴（审片速查）

表面化表演（挑眉做鬼脸描绘情绪）｜预演结果（第一秒就在演结局）｜等待台词｜策略单一（全程一种色彩）｜图解式手势（动作重复台词意思）｜廉价情绪（无触发的哭与怒）｜身体与经历不符｜威胁前摇（施暴前凶狠停顿、缓慢转头）｜同步群像｜死气沉沉的停顿｜情绪重置｜评价式表演（向观众使眼色）｜特写过载（近景面部肌肉过度活跃）｜死鱼眼。

命中任一项：记录时刻、人物、图鉴条目名与可见证据；按影响定级，特写与主角从严。

## 5. 表演评分锚点（0–5，供模块内校准）

0 假人：无行为。1 朗诵者：表面情绪＋图解动作。2 勤勉者：有目标但策略单一、反应滞后、停顿空洞。3 熟练工：有目标与节奏点、能倾听、身体合理；缺潜台词与状态惯性。4 活人：行为连续、策略有反差、反应先于台词、至少一个出人意料但真实的选择。5 磁石：同时演两层真实（双重真实）。

模块得分映射：锚点 4–5 → 20–25 分；3 → 14–19；2 → 8–13；0–1 → 0–7，再叠加四项必查的扣分。
