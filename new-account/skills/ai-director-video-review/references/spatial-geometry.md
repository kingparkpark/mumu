# 空间几何审查（硬闸 G1/G2 执行标准）

审片最常见的错位：只核"物在、人在、方向朝前"，不核关系。本标准把空间判断从印象改为连线验证。所有验证在全分辨率帧上进行，缩略帧条只用于定位候选时刻。

## 1. 敌我连线测试（掩体成立的唯一标准）

对每一名处于交火、追击、威胁关系中的人物，逐人执行：

1. 在全分辨率帧上标出该人物的位置 P、威胁源（敌方射手/火力点）位置 T。
2. 连线 P–T 即火力线。掩体（车、墙、沙袋）必须与这条连线相交，且遮挡住人物的躯干要害，才算"在掩体后"。
3. 反向验证：从 T 的视角看向 P，中间是否被掩体挡住。摄影机视角下"人躲在车后面"若只是摄影机—车—人共线、而敌方在另一侧，判定掩体不成立。
4. 人物探出掩体的部分（头、肩、枪口）应是主动射击/观察的最小暴露；全身位于火力线内且无遮挡 = 暴露。

判级：掩体不在连线上、人物在开阔地交火 = `critical`（G1 不过）。掩体部分遮挡、暴露面积过大 = `major`。仅探头观察等合理暴露 = 通过并记录。

## 2. 暴露审计

逐人核查：谁在敌方视线与射程内、身体有多少在掩体外、此刻暴露是否有行为理由（正在移动、正在压制射击、正在观察）。无理由的直立、静止、松弛姿态出现在交火窗内 = `major` 起步；若同时全员如此 = 场景行为逻辑崩坏，`critical`。

## 3. 轴线与对峙方向

- 对峙轴线：交战/对峙双方的连线即轴线。双方的朝向、枪口方向、视线方向必须沿轴线互指；任何一方朝向偏离轴线超过约 30 度且无目标依据（侧翼敌人、第二威胁）= 方向错误 `major`。
- 屏幕方向：同一人物跨镜移动方向、双方在画面中的左右关系应保持一致；翻转必须有声明的轴线重置（环绕镜头、明确的机位越轴过程）或新建立镜头，否则 = `major`（failure atlas：screen direction flips）。
- 视线匹配：A 看向画外右侧，B 的反打镜头中应看向画外左侧且高度相称；视线无对象、两人同向看同一侧 = `minor` 起步，对话/对峙场景升 `major`。
- 火力落点：弹着点（火花、尘点、弹孔）应出现在被射击一方的掩体与墙面上；落点出现在射击者自己一侧或无人方位 = 方向链断裂 `major`。

## 4. 距离与尺度

- 声明距离（如"50 米外"）与画面尺度核对：远端人物在画面中的相对高度应明显小于近端人物；两镜之间同一组人物的相对距离不得无因骤变。
- 交火双方在同一镜头内近大远小的透视关系应与地理声明一致；敌方身影与主角等大却声称在远处 = `major`。

## 5. 地理与设施排他

- 建立本段设施清单（来自创作意图/分镜），逐帧核对：清单外出现工事、车辆、建筑、门洞 = `major` 起步。
- 关键锚点（掩体车辆、路障、出口）在镜头间的相对方位应一致；锚点换边、换形 = `major`，主体锚点消失 = `critical`。
- 出入口与来路：人物的进出位置应与地理一致；从不存在的开口出现 = `major`。

## 6. 报告写法

硬闸问题必须给出：帧时刻、人物代号、连线两端（人物—威胁源）、掩体与连线的关系（相交/不相交/部分）、判级依据。只写"掩体似乎不合理"不算完成硬闸。
