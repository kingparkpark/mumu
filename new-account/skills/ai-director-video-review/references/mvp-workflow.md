# MVP 2.0 执行流程

## 1. 建立审片上下文

记录工作模式、内容类型、视频目标、时长、画幅、参考素材和有意变化。没有创作意图时，按通用发布前质检并声明假设。

## 2. 获取可观察素材

优先直接查看视频。若环境暂不支持视频理解，则抽取：镜头切换附近帧、固定间隔帧，以及疑似异常前后帧。

### 采样协议（最低标准，低于此标准不得下对应结论）

| 内容类型 | 最低采样 | 可下的结论 |
|---|---|---|
| 单人慢动作、静态场景 | ≥2fps ＋关键帧全分辨率 | 结构与连续性 |
| 快速动作、物体交互、换位、段界 | ≥4fps，换位与段界处间隔 ≤0.25 秒 | 动作连续性 |
| 多人同框动作（群像、交火、追逐） | 动作窗 ≥8fps ＋逐人动作起止表 | 同步/冻结/反应链结论 |
| 空间几何（掩体、轴线、距离） | 关键时刻全分辨率帧 ＋连线验证 | 硬闸 G1/G2 |

- **全速观看**：具备视频通道时，必须先以正常速度完整看一遍，再抽帧核查（正常速度看全片、脆弱帧暂停，是专业 QC 的基本动作）。只有帧证据时，报告必须声明"未做全速观看"，证据置信度上限为 `medium`；含多人同框动作的内容，表演模块不得判为通过、结论不得为 `ready`。
- 抽帧会系统性少报运动层问题（变形、漂移、接缝、时序、同步）。不得凭低密度抽帧宣称运动层"已修好"或"无同步"。

## 3. 三轮检查

- 第一轮：全速完整观看，理解叙事、镜头边界和整体节奏，过普通观众关——故事是否同一件、行为是否真人会做的、时机位置对不对、空间因果读不读得出；标记候选时间段。
- 第二轮：前置硬闸。按 [空间几何审查](spatial-geometry.md) 做敌我连线、暴露、轴线、距离与设施排他核对；按 hard-fail 清单核身份与数量。硬闸问题先于一切分数记录。
- 第三轮：围绕候选时间段密集采样，按八模块确认问题和替代解释；多人动作段落先建逐人动作起止表，再执行 [表演与行为审查](behavior-acting.md) 四项必查。

## 4. 形成证据链

对每个候选问题回答：看到了什么、与哪个时间点或标准冲突、是否可能是有意变化、对成片有什么影响、最小返修动作是什么。证据不足则降置信度或列为待确认。观察与推断分开；同步、方向、掩体三类结论必须分别给出起止表、轴线、连线作为证据，不接受印象式表述。

## 5. 输出报告

给出四级发布结论（受硬闸与表演模块封顶规则约束）、最优先的 1–3 个返修项、结构化问题表、技术质量、目标适配、置信度、优点、假设与限制。建议应指向具体片段和动作，例如"以 00:03.2 的角色帧为参考，重生成 00:04.2–00:05.8"，避免只写"增强一致性"。多条素材还要形成比较或跨镜结果，最后生成批量汇总。

## MVP 验收条件

- 硬闸已执行并有连线级证据，或明确声明为何证据不足（此时结论不得为 `ready`）。
- 八类标准均被覆盖，或明确说明为何不适用；含多人动作时表演四项必查有起止表支撑。
- 每个缺陷都有时间定位和可见证据。
- 观察与推断分开，未虚构参数。
- 严重程度与返修优先级一致。
- 报告能让创作者直接决定保留、局部返修或重生成。
- 自媒体场景明确回答"能不能发"和"最快怎么修"。
- 批量模式中每条独立内容都能通过原文件名直接识别；内部唯一 ID 不干扰用户阅读。
