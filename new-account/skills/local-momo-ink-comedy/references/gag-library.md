# 笑点弹药库

> 写稿时按"情境×笑点类型×反转"组合。每集：1 主笑点 + 2 辅笑点。角色名一律用「墨团团」。

## 物理笑点（汤姆杰瑞经典）
1. **滑倒类**：踩墨渍滑倒、踩香蕉皮、踩自己甩出的墨点。
2. **压扁类**：门夹、重物落下压成纸片（掀起来抖一抖复原）。
3. **弹飞类**：弹簧、弹弓、被自己拳头后坐力弹飞。
4. **撞墙类**：追太猛撞墙/穿墙画洞/撞出人形凹坑（墨水会留下墨印）。
5. **悬挂类**：挂在悬崖边/桌沿，墨滴手指一个一个松脱。
6. **抛物线类**：食物/东西抛接，最后砸自己头上。

## 墨水专属笑点（本 IP 差异化）
1. **变错形状**：想变大拳头结果变出小手；想变伞结果变漏斗。
2. **变身翻车**：想变身魔王只变出一半（只有四只手没有角）；威吓到一半打喷嚏变回萌犬；魔王形态撞门框。
3. **威吓→露怯→强撑三连**：摆出最凶的 pose → 看到水瞬间怂 → 硬撑着腿抖（本 IP 招牌）。
4. **分裂失控**：分身不听话，反过来捉弄本体。
5. **被水制裁**：泼水瞬间瘫成墨渍，对手踩上去又滑倒（双重笑点）。
6. **伪装穿帮**：变成花瓶被端走、变成地毯被踩、变篮球被拍。
7. **弹性误伤**：拉长身体当弹弓，松手把自己弹进垃圾桶。
8. **融合同化**：对手沾上墨，也长出墨尾巴/墨耳朵（误变异），铃铛叮铃铃响。

## 情境×对手素材库（每集换对手）
- **流浪猫**：抢鱼干、领地大战（猫追狗经典）、互相吓唬（墨团团用魔王形态威吓猫）。
- **邻居狗**：抢飞盘、抢骨头、比谁拆家快。
- **快递员/外卖员**：以为是食物的大纸箱、无人机抢包裹。
- **扫地机器人**：把墨团团当污渍反复吸、墨团团骑机器人反向清洁。
- **吸尘器**：反向开吸，墨团团被吸进去又喷出来（变成各种形状）。
- **小主人/小孩**：小孩的玩具大战、蜡笔涂鸦出墨水怪物。
- **水管工/下雨天**：水=天敌，全城躲雨，防水衣闹剧（顺便触发"被水浇塌回萌犬"）。
- **镜子/雕像**：墨团团对镜子里的自己挑衅（分身戏）。

## 反转公式
- **陷阱反弹**：设的陷阱被自己踩中。
- **差一点**：每次快成功时差一点点（门缝、台阶、尾巴尖）。
- **乱入**：第三个角色/物体半路杀出改变局面。
- **大材小用**：憋大招只打出小效果（反差）。
- **二重反转**：对手躲过 A 陷阱，踩中 B 陷阱（自己挖的）。

## 组合模板（可直接套用）
- **模板 A「追与反杀」**：对手抢物→墨团团追击→设陷阱→对手躲开→墨团团踩自己陷阱→将计就计用身体变形反杀。
- **模板 B「误会被整」**：墨团团被误认成某物→解释失败→误会升级→墨团团将错就错大闹→真相揭晓双方都狼狈。
- **模板 C「神器翻车」**：新对手带"神器"（吸尘器/吹风机/水枪）→克制墨团团→墨团团偷走神器→神器反噬对手→墨团团得意时神器又坏掉。
- **模板 D「威吓失败」**：墨团团变身魔王想吓退对手→对手没被吓到（或一滴水浇塌）→露怯→硬撑→靠智取（分身/潜行）翻盘。
