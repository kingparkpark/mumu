# 墨团团 — 汤姆和杰瑞式喜剧短片脚本

本技能为 AI 短片 IP「墨团团」服务：一只由液态墨水构成、能像毒液一样自由变形的小狗（可爆发变身「四臂魔王」），以《猫和老鼠》式的故事结构和夸张表演制作每集 30–60 秒喜剧短片。**风格一旦锁定，必须全程遵守，不允许漂移成温情日常、热血战斗或抽象意识流。**

## 使用流程

### 1. 识别任务
用户要写该 IP 的单集脚本、剧本、分镜、笑点方案，或要把某一集做成 AI 视频提示词时，进入本技能。先判断输入里是否已包含：本集情境/对手、笑点主题；缺失时按第 3 步补齐。

### 2. 加载风格锁（必读，不可跳过）
每次写脚本前，必须依次 Read 以下文件并以其为硬约束：

- `references/ip-bible.md` — 角色与世界观（墨团团的形象、双形态、能力、规则、弱点、行为准则）
- `references/story-style.md` — 故事风格锁（四段式结构、节奏、笑点密度、反转与结局原则）
- `references/performance-style.md` — 表演方式锁（弹性形变、表情放大、速度表演、音效化、节奏点）
- 需要现成笑点时查阅 `references/gag-library.md`
- 照抄输出格式时参考 `references/script-template.md` 和 `references/sample-episode.md`

### 3. 确定单集要素
优先使用用户给出的要素；缺失时按以下默认规则生成：

- **对手**：每集换一个（流浪猫、邻居狗、快递员、扫地机器人、吸尘器、外卖无人机、小主人、下雨天……），从 gag-library 的「情境×对手素材库」抽取并配对情境。
- **情境**：一个日常场景 + 一个冲突源（食物、玩具、领地、误会、快递、门、镜子……）。
- **笑点目标**：1 个主笑点（本集记忆点）+ 2 个辅笑点（节奏填充）。
- 用户已给出足够要素则直接成稿；若对手/情境/主笑点缺失且无法合理推断，才向用户确认一次再写。

### 4. 按模板撰写单集脚本
用 `references/script-template.md` 的结构写完整一集（默认 60 秒，可缩到 30–45 秒）：集信息、角色表、四段式 beat 表（时间轴+镜头+画面+表演注记+音效+节奏点）、结尾定格、分镜→视频提示词转换表、质检清单自检。

### 5. 质量自检（交付前必做）
对照以下清单逐项打勾，任一不满足必须修改后再交付：

- [ ] 结构是四段式：追逐→设局→反转→惩罚（自作自受）
- [ ] 每 8–15 秒一个笑点/小反转；60 秒全片至少 5 个笑点，30 秒至少 3 个
- [ ] 台词极少：能用动作和音效讲的笑话不用对白；拟声词已写入每个 beat 的音效列
- [ ] 台词锁定溯源（假锁定零容忍）：所有标注为"已锁定/用户确认"的台词，必须已逐字对照用户原话确认过的锁定文本；凡是助手自己起草、用户未逐字确认的台词，一律不得标为锁定——要么删成无台词版（用动作和音效讲），要么明确标注"草稿台词，未锁定，待用户逐字确认"
- [ ] 表演含弹性形变（squash & stretch）和表情放大；墨水/变身专属表演（变形三阶段、魔王形态、分身、橡皮筋弹回、被水瘫软）至少出现 1 次
- [ ] 没有流血、受伤、死亡、黑暗化；恶作剧全部卡通化无害，对手下集还能回来
- [ ] 对手有表演弧（至少一次表情崩溃/夸张反应），不是木头人
- [ ] 结尾定格 pose + 主笑点呼应标题
- [ ] 每个 beat 已附视频生成提示词（或提示词转换表完整），可直接喂给图生视频工具

### 6. 交付
输出完整单集脚本（中文）。若用户要求，可同时给出：封面标题、发布文案（15 秒钩子）、标签。
