# Keep a correction local

## Test whether the correction is general

- Read the correction in its own words before you act on it.

- Treat a correction as local to the scene, line, or clip it named unless the user said it applies everywhere.

- Ask the user whether a correction is general when the wording could cover one scene or the whole series.

- Do not infer a general rule from a single example, a single clip, or a single line the user rejected.

- Do not infer a general rule from the tone of a correction, because a blunt correction is still a local correction unless the user says otherwise.

## Apply it only where it was pointed

- Change only the scene, line, or clip the user pointed at.

- Leave the same behaviour in place elsewhere when the correction named one place.

- Judge each later scene fresh from its own situation instead of carrying the last correction into it.

- Remove a standing rule you created from a local correction as soon as the user says it was too broad.

- Say plainly in your reply that the change is local when you apply a local correction, so the user can see the scope you used.

## Record only what the user made general

- Write a standing rule into memory or a ledger only when the user used general wording or said the point applies generally.

- Quote the user wording that made the rule general beside the rule you record.

- Keep a local correction out of memory, out of a ledger, and out of a skill when no general wording supports it.

- Check an existing standing rule before you reuse it and drop it when its source was one local correction.

- Offer the general version as a question first when you think a local correction might deserve to become general, and wait for the user to approve it.

## Alternatives for better results

- Split a correction that touches several scenes into one local change per scene, so each change can be checked on its own.

- Ask the user to confirm the exact span a correction covers when the correction is ambiguous instead of widening it yourself.

- Keep the corrected version beside the previous version for one round, so a too broad change can be undone without rewriting the whole piece.
